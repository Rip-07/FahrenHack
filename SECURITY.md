# Безопасность

## Как проверить, что exe настоящий

- Официальные сборки собираются в GitHub Actions из исходников этого репозитория (`.github/workflows/build.yml`). Рядом с каждой сборкой опубликован SHA-256.
- Ни упаковщиков, ни обфускации нет: можно собрать самому командой `cargo build --release` и сравнить поведение.
- FahrenHack **никогда не просит отключить антивирус**. Он не скачивает и не запускает код из интернета, не внедряет DLL в игры и не устанавливает драйверы.

## Что FahrenHack делает с системой

- Читает и пишет память только того процесса игры, к которому вы подключились, через стандартные `ReadProcessMemory` и `WriteProcessMemory`.
- Не подключается к процессам с античитом.
- Запускает локальный веб-сервер на `127.0.0.1`. Сеть доступна только при включённом пульте, и каждый запрос требует секретный ключ из QR-кода. Ключ меняется кнопкой «Новый ключ».
- Хранит настройки и калибровки в `%APPDATA%\FahrenHack`. Снимок памяти для поиска временно пишется во `%TEMP%` и удаляется после использования.

## Сообщить об уязвимости

Не публикуйте детали уязвимостей в открытых issue. Используйте приватный отчёт на GitHub: вкладка **Security → Report a vulnerability**.
