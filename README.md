<h1 align="center">FahrenHack</h1>

<p align="center">Открытый трейнер для одиночных игр на ПК: интерфейс в стиле игровой консоли, готовые профили игр и пульт на телефоне.</p>

> **Только для одиночных игр.** FahrenHack не подключается к играм с античитом и не обходит защиту. Не используйте его в онлайн-режимах. Проект не связан с разработчиками и издателями игр. Названия игр упоминаются только для указания совместимости. Подробнее в [LEGAL.md](LEGAL.md).

*English: FahrenHack is an open-source (MIT) trainer for single-player PC games. It has a console-style UI with gamepad support, ready-made game profiles and a phone remote over the LAN. Written in Rust, Windows 10/11 x64.*

## Возможности

- **Библиотека игр.** Плитки с обложками из вашего локального кэша Steam (в проект они не входят). Видно, какие игры установлены и запущены, игру можно запустить через Steam.
- **Готовые профили.** Для игры заранее описаны читы: что делает каждый, тип значения, значение по умолчанию и горячая клавиша. Первый профиль сделан для **Resident Evil 4 (2023)**.
- **Автоподключение.** Когда запускается игра с профилем, FahrenHack подключается к ней сам.
- **Мастер настройки.** Каждый чит один раз «находится» на вашей версии игры за 1–2 минуты. Затем FahrenHack ищет цепочку указателей, и чит работает после перезапуска игры без повторной настройки.
- **Консольный интерфейс.** Окно без рамки и полноэкранный режим (F11). Управление стрелками или геймпадом: A — выбрать, B — назад, LB/RB — разделы, Y — выключить все читы.
- **Горячие клавиши** работают прямо в игре: `F1`, `CTRL+F2`, `SHIFT+NUM5` и т.п.
- **Пульт на телефоне.** Тот же интерфейс в браузере телефона по Wi-Fi, вход по QR-коду. По умолчанию выключен.
- **Сканер для любой игры** в духе Cheat Engine:
  - точный поиск и поиск неизвестного значения через снимок памяти;
  - отсев по «больше / меньше / изменилось / не изменилось»;
  - сохранение найденного как своих читов.

## Быстрый старт

1. Скачайте `fahrenhack.exe` из Releases или соберите сами (см. ниже).
2. Запустите **от имени администратора**: без этого Windows не даст открыть память многих игр.
3. Запустите игру. Она появится на главном экране с меткой LIVE, а FahrenHack подключится сам.
4. Откройте «Читы». У чита, который ещё не настроен, нажмите **«Настроить»** и следуйте подсказкам:
   - **видимое число** (песеты, патроны): введите число → «Искать» → измените его в игре → введите новое → «Отсеять»;
   - **скрытое значение** (полоска здоровья): «Снимок» → получите урон → «Уменьшилось» → подождите → «Не изменилось» → вылечитесь → «Увеличилось».

   Когда останется несколько адресов, проверьте их кнопкой «Записать» и нажмите «Это оно».
5. Включайте читы переключателем или горячей клавишей.

Если после запуска с новой версией игры чит показывает «Войдите в игру», загрузите сохранение. Если значение странное, нажмите «⋯» → «Перенастроить».

## Как работают готовые профили

Трейнеры вроде WeMod хранят для каждой версии игры адреса, найденные вручную. FahrenHack устроен так:

1. Профиль (`games/*.json`) описывает читы и способ их найти: подсказки мастера, тип значения, значение по умолчанию.
2. На вашем ПК мастер один раз находит значение, а поиск указателей строит цепочки вида `re4.exe+0x…→0x…→0x…`. Калибровка сохраняется **для конкретной сборки игры**: она определяется по заголовку exe.
3. После следующего запуска игры FahrenHack сам вычисляет адрес по цепочке. Если вы настроите чит ещё раз в новом сеансе, цепочки сверятся и останутся только подтверждённые.
4. Проверенные цепочки можно добавить в профиль, в раздел `builds`. Тогда у всех с той же сборкой игры чит заработает сразу, без настройки. Так профили становятся по-настоящему «предустановленными».

Профиль также может использовать байтовые сигнатуры (`aob`), фиксированные цепочки (`pointer`) и патчи кода (`patch`). Правила для таких профилей описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

## Пульт на телефоне

Раздел «Пульт» → «Включить пульт». Отсканируйте QR-код телефоном в той же сети Wi-Fi. Если Windows спросит про брандмауэр, разрешите доступ для частных сетей. Ссылка содержит секретный ключ. Кнопка «Новый ключ» отключает старые ссылки.

## Сборка

Нужны Windows 10/11 x64, [Rust](https://rustup.rs) (toolchain MSVC) и Visual Studio Build Tools с Windows SDK. WebView2 уже есть в Windows 11.

```bash
cargo build --release
```

Готовый файл: `target\release\fahrenhack.exe`. Иконка рисуется из `src/logo.rs` при сборке и встраивается в exe.

```bash
cargo test
```

### Параметры запуска

| Команда | Что делает |
|---|---|
| `fahrenhack` | окно приложения |
| `fahrenhack --browser` | интерфейс в обычном браузере |
| `fahrenhack --headless` | только сервер, ссылка в консоли |

Данные лежат в `%APPDATA%\FahrenHack`: настройки, калибровки, свои читы, свои профили. Путь можно переопределить переменной `FAHRENHACK_DATA`.

## Структура

| Путь | Что внутри |
|---|---|
| `src/mem.rs` | чтение и запись памяти процесса, регионы, модули, стеки потоков |
| `src/scan.rs` | сканер: точный поиск, снимок памяти, отсев |
| `src/pointer.rs` | цепочки указателей и поиск указателей |
| `src/aob.rs` | байтовые сигнатуры |
| `src/profile.rs` | профили игр, калибровки, свои читы |
| `src/app.rs` | состояние, читы, мастер, фоновые потоки, защита от античитов |
| `src/web.rs` | локальный HTTP API и раздача интерфейса |
| `src/window.rs` | окно на WebView2 (tao + wry) |
| `src/ui/` | интерфейс: HTML, CSS, JS |
| `games/` | встроенные профили игр |
| `tools/` | тестовая «игра» `dummy-game`, сквозной тест `e2e.ps1`, проверка настоящего окна `window-check.ps1` |
| `AGENTS.md`, `docs/STATUS.md` | инструкции для ИИ-агентов (Codex и др.) и текущее состояние проекта |
