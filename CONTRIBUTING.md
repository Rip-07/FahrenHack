# Как добавить игру или улучшить профиль

Профили лежат в `games/*.json` и встраиваются в программу при сборке. Чтобы проверить профиль без пересборки, положите файл в `%APPDATA%\FahrenHack\games\`: он заменит встроенный профиль с тем же `id`.

## Правила для профилей

1. **Только одиночные игры и режимы.** Не принимаются профили для онлайн-режимов, игр с античитом, рейтингов и соревнований.
2. **Без платного контента.** Никаких читов на DLC, микротранзакции, внутриигровую валюту за реальные деньги и разблокировку лицензий.
3. **Без обхода защиты.** Патчи (`patch`) не должны отключать DRM, anti-tamper, проверки целостности или античит. Файлы игры на диске не изменяются никогда.
4. **Только свои находки.** Не копируйте таблицы Cheat Engine, скрипты и офсеты из чужих трейнеров и форумов. Значения ищите сканером FahrenHack. Если находка чужая, получите разрешение автора и укажите его.
5. **Без ассетов игры.** Никаких логотипов, обложек, скриншотов и текстов из игры. Описания читов пишите своими словами.

## Формат профиля

```json
{
  "id": "mygame",
  "title": "Название игры",
  "subtitle": "Год или издание",
  "processes": ["game.exe"],
  "steam_appid": 123456,
  "accent": "#2b4c6f",
  "notes": "Подсказка, которую видит игрок",
  "pointer_scan": { "max_depth": 5, "max_offset": 4096 },
  "cheats": [
    {
      "id": "money",
      "category": "Ресурсы",
      "icon": "coin",
      "name": "Деньги",
      "description": "Что делает чит",
      "kind": "set",
      "vtype": "i32",
      "value": "999999",
      "hotkey": "F3",
      "locator": { "type": "calibrate", "mode": "exact", "prompt": "Сколько у вас денег?", "steps": ["Шаг 1", "Шаг 2"] }
    }
  ],
  "builds": {}
}
```

### Поля чита

- `kind`: `freeze` держит значение, пока чит включён; `set` записывает значение по нажатию.
- `vtype`: `i32`, `i64`, `f32` или `f64`.
- `value`: значение по умолчанию. Для `freeze` значение `null` означает «держать то, что было в момент включения».
- `hotkey`: клавиша вроде `F1`, `CTRL+F2`, `SHIFT+NUM5`, `ALT+K`.
- `icon`: `heart`, `ammo`, `coin`, `gem`, `knife`, `star`, `bolt`.

### Способы найти значение (`locator`)

| `type` | Что это |
|---|---|
| `calibrate` | Мастер находит значение на ПК игрока: `mode: exact` для видимого числа, `unknown` для полоски. Затем FahrenHack строит цепочки указателей. |
| `pointer` | Фиксированная цепочка: `{ "module": "game.exe", "offsets": ["0x1234", "0x10", "0x8"] }`, то есть `[[game.exe+0x1234]+0x10]+0x8`. |
| `aob` | Байтовая сигнатура в модуле. Необязательный `rip: [смещение_disp32, длина_инструкции]` для RIP-адресации, затем `offsets` как у `pointer`. |
| `patch` | Замена байтов по сигнатуре: `pattern`, `offset`, `bytes`. При выключении исходные байты восстанавливаются. |

### Проверенные цепочки (`builds`)

После настройки чита FahrenHack сохраняет цепочки в `%APPDATA%\FahrenHack\calibration\<game>\<build>.json`. Сборка игры определяется по заголовку её exe и выглядит так: `5f3a2b1c-1a2b000`.

Цепочку можно добавить в профиль, если она **подтверждена минимум в двух запусках игры**: `confirmations` ≥ 2, и после перезапуска чит находил верное значение. Пример:

```json
"builds": {
  "5f3a2b1c-1a2b000": {
    "money": [ { "module": "game.exe", "offsets": ["0x2F1A8C0", "0x18", "0x2C4"] } ]
  }
}
```

С таким разделом чит на этой сборке работает сразу, без настройки.

## Перед pull request

```bash
cargo test
```

Тест `builtin_profiles_parse` проверяет, что встроенные профили читаются: в них уникальные `id`, корректные клавиши и значения.
