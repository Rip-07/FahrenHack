# Состояние проекта

*Обновлено: 22.11.2026, этап 1 функциональности уровня WeMod (движок и интерфейс).*

## Готово и проверено

- Движок проверен на `tools/dummy-game`; `tools\e2e.ps1` проходит все 30 проверок:
  - подключение к процессу и автоподключение по профилю;
  - точный поиск и поиск скрытого значения через снимок памяти;
  - поиск указателей: лучшая найденная цепочка совпадает с реальной структурой `static → +0x40 → +0x18`;
  - заморозка и запись значений;
  - после перезапуска игры читы находятся сами, повторная настройка подтверждает цепочки;
  - **инъекция кода** через код-пещеру: включение, выключение с восстановлением кода, параметр, который ползунок меняет на лету, отказ при двух патчах одного кода, «Выключить все»;
  - **числа** (запись, шаг, предел), **ползунки**, **списки**, закрепление, вторая клавиша.
- Новые элементы интерфейса проверены в настоящем окне через CDP:
  - группа «Закреплённые», сворачиваемые категории с иконками и счётчиками;
  - «−», поле, «+» для чисел; ползунок с подписью; список с «Применить»;
  - подсказки «i» и «!», клавиши «↑»/«↓».
- Окно приложения проверено через `tools\window-check.ps1`: интерфейс загружается, кнопки «развернуть», «восстановить» и «свернуть» работают, перетаскивание за шапку реальной мышью работает.
- Интерфейс проверен в браузере на ПК и в ширине телефона 375 px:
  - главный экран, страница игры, меню чита;
  - мастер настройки от снимка до привязки;
  - сканер, пульт (выключенное состояние), настройки.
- Юнит-тесты: 9/9.
- Документы: README, LEGAL (правовой обзор), CONTRIBUTING (правила профилей), SECURITY, CI-сборка в `.github/workflows/build.yml`.

## Не проверено

- **Настоящий Resident Evil 4.** Профиль `games/re4r.json` описывает 5 читов (здоровье, патроны, нож, песеты, шпинели), но ни один ещё не откалиброван на реальной игре. Раздел `builds` пустой.
- Пульт с настоящего телефона: LAN-слушатель, QR, брандмауэр.
- Геймпад: навигация, A/B/LB/RB/Y/View/Start.
- Изменение размера окна за края, разворачивание без рамки (не закрывает ли панель задач), полный экран по F11.

## Следующие шаги

0. **Читы RE4 уровня WeMod.** Список желаемого — у владельца (скриншоты WeMod). Движок и интерфейс для них готовы (этап 1). Что осталось:
   - **этап 2, данные через калибровку:** песеты, шпинели, золотые и серебряные жетоны, очки CP, время игры, маленькие ключи, стаки предметов. Перевести их в `number` или `slider`;
   - **этап 3, исследование кода на запущенной игре** (`inject`/`patch`): неуязвимость, броня, бесконечные предметы, крафт, бесплатный торговец, отдача, перезарядка, точность, скорострельность, урон, убийство с одного выстрела, скорость игры, FOV, полёт сквозь стены, ранг S+, режим «Наёмники». Для этого нужен инструмент «что записывает в этот адрес» и дизассемблер (например, крейт `iced-x86`). Защита RE4 может закрывать игру при отладке; обходить её нельзя (см. правила).
   - **не делаем:** редактор Exclusive Upgrade Tickets — они продаются за реальные деньги.
1. **Откалибровать RE4** на сборке владельца: запустить игру, загрузить сохранение, пройти мастер для каждого чита. Перезапустить игру, настроить ещё раз до `confirmations` ≥ 2. Перенести подтверждённые цепочки из `%APPDATA%\FahrenHack\calibration\re4r\<build>.json` в `games/re4r.json` → `builds`. Тип прочности ножа не известен: возможно, нужно `f32`.
2. **Доделать аудит окна.** Аудит начинался, но прервался вместе с сессией Claude Code. Что проверить:
   - **JS-среда WebView2:** `confirm()`, `navigator.clipboard` на `http://127.0.0.1`, автозапуск звука, Gamepad API;
   - **окно без рамки:** изменение размера за края, разворачивание и панель задач, двойной клик по шапке для разворачивания после `drag_window()`;
   - **ввод:** стандартные клавиши WebView2 (F5, Ctrl+R, F12, Ctrl+колесо, Alt+F4, кнопки мыши «назад» и «вперёд»), фокус при открытии окна; при фокусе в окне FahrenHack горячая клавиша срабатывает и через `GetAsyncKeyState`;
   - **жизненный цикл:** закрытие кнопкой и по Alt+F4 должно вызывать `on_exit` (восстановление патчей) и завершать процесс. Второй экземпляр: два потока горячих клавиш переключат чит дважды, нужна защита от второго запуска. Резервный путь без WebView2.
3. **Git.** Сделать `git init`, первый коммит и при желании репозиторий на GitHub, тогда CI будет собирать релизы.
4. **Перед публикацией** (см. LEGAL.md):
   - убедиться, что бренд FahrenTech принадлежит владельцу;
   - проверить название FahrenHack по базам товарных знаков;
   - вписать имя в `LICENSE`.

## Идеи

- Экранная цифровая клавиатура для ввода чисел с геймпада.
- Защита от запуска второго экземпляра: активировать уже открытое окно.
- Поиск указателей на больших играх: прогресс, отмена, ограничение памяти. Сейчас лимит — 120 млн пар указателей.
- Экспорт и импорт калибровки, чтобы делиться с другими игроками и пополнять `builds`.
